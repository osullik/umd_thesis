Graph data structures and the algorithms that operate on them are foundational to computer science.
Since the early days of the field, they have been a focal point for theoretical computer science.

The Intelligence and Security (I\&S) community uses graphs to structure collected information, analyze it, and generate insights to drive operations in the national interest.

However, the billions-to-trillions of edges scale the I\&S deals in, the dynamic nature of graphs, temporal constraints on data possession and the criticality of their work create an imperative to improve the \textit{efficiency} and \textit{effectiveness} of large-scale graph analysis.

Improvements can typically come from three sources.
First, the \textit{algorithms} used to analyze the graphs can be improved, or modified to operate in a time-constrained setting, for example by implementing early-stopping, incremental solving or sampling. 
Second, the underlying \textit{data structure/implementation paradigm} can be modified to exploit new technologies, for example by moving to shared memory parallelism or switching from the canonical `pointer and memory-block' representation to a linear algebraic representation. 
The third major avenue for improvement is using \textit{hardware acceleration} to operate on graphs more \textit{efficiently} and \textit{effectively}, for example by reducing network latency in distributed systems or reducing memory access latency.

This Thesis focuses on exploring \textit{Hardware Acceleration} for graph processing.
In particular, it explores if and when graph hardware accelerators should be used, and demonstrates how the process of comparing across hardware architectures can generate insights about the problems themselves that can inform future algorithmic and implementation work.
