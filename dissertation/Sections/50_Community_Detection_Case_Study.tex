\chapter{The Population Segmentation Problem}
\label{chapter:50-Community-Detection-Case-Study}
This chapter demonstrates how the \gai benchmark design process described in chapter~\ref{chapter:40-Graph-AI-Benchmarking} can be applied to an I\&S domain use case to develop a problem for the \gai benchmark framework. 

The \textit{Identify Use Case} step is not included as a detailed description here because the work in chapter~\ref{chapter:10-Introduction} to identify the I\&S problems (table~\ref{table:problem-survey}) identified it as a suitable use case. 
To identify other use cases the same methodology can be applied to other domains.
