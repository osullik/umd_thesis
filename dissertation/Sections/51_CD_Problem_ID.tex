\subsection{Tasks}
Graph Partitioning is the top-down task of optimally dividing a graph into $K$ subgraphs such that each vertex belongs to exactly one partition, all partitions are disjoint, and some objective function is optimized. 
Graph Clustering is the bottom-up task of optimally clustering a set of vertices such that each vertex belongs to exactly one cluster, all clusters are disjoint, and some objective function is optimized.

\subsection{Datasets}
Population segmentation focuses on human social networks, which are typically scale-free (see: section~\ref{section:22-graph-topology}).
The community definition reinforces that graph topologies are expected to consist of smaller densely connected subgraphs within the containing graph.
At the extremely defined end of `communities,' a graph will consist of cliques (completely connected subgraphs), connected to other cliques by single-edge `bridges'. 
At the extremely undefined end, a fully connected graph or multigraph has no topological community structure and attributes must be included.
