\section{Our Graph-Based Artificial Intelligence Taxonomy}
\label{section:12-graph-based-ai}
The \gai Benchmark Framework defines Graph-Based Artificial intelligence (\gai) as a taxonomy of intelligence algorithms and machine learning models that learn and reason over information represented in graph data structures.

\input{Figures/Diagrams/13_gai_taxonomy}

Prior efforts to define a taxonomy of \gai focus primarily on \textit{Graph Neural Network}~\cite{Smith2021, Zhou2020a}, \textit{Graph Mining}~\cite{Chen2022a} or specific problems like signal processing~\cite{Xia2021}.
We extend these taxonomies to include:
\begin{itemize}
    \item \textbf{\ac{GPS}.} Are classic AI tasks formulating the world as a graph, including navigation and critical path analysis.
    \item \textbf{\ac{GM}.} Are tasks that analyze the structural characteristics of a graph, including spatial pattern matching and community detection. 
    \item \textbf{\ac{GR}.} Are \ac{AI} tasks that use graphs for inference, like common sense reasoning and knowledge-graph question answering. 
    \item \textbf{\ac{GA}.} Are tasks that transform graphs into other structures for downstream tasks, such as generating embeddings or graphs from statistical properties.
    \item \textbf{\ac{GP}.} Are tasks that learn directly on graphs typically using \ac{GNN}s, including knowledge graph completion and anomaly detection. 
    \item \textbf{\ac{GT}.} Are tasks that use graphs to improve generative models' transparency, explainability, and interpretability. 
\end{itemize}

The taxonomy contextualizes \gai as part of the existing AI landscape and provides a few examples \gai tasks that sit within each \gai category. 
The \gai problem areas anchor the development of the \gai benchmark problems within the framework and emphasize the diversity of tasks that the hardware and software systems that run \gai need to support.
