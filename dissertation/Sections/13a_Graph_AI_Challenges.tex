\section{Challenges in Evaluating \gai}
\label{section:13-graph-based-ai-challenges}

\input{Figures/Diagrams/14_gai_challenges}

A hierarchy of challenges affects \gai (Figure~\ref{figure:gai-challenges}).
The data dependence of graph processing is a core challenge. Graphs of different shapes and sizes vary the algorithmic complexity and exacerbate the irregular memory accesses and computation patterns that undermine spatial and temporal locality. 
Graphs have no standard accepted method to represent them, abstract operations, or develop primitives, meaning there have been no coherent development efforts to accelerate graph processing generally. 

\gai problems are intrinsically linked to graph problems. 
Each \gai problem in the taxonomy has different computational characteristics and behaves differently on the same data. 
Graph processing is the bottleneck in \gai, meaning that improving \gai performance is directly dependent on elevating the graph processing bottlenecks. 

The real world adds further constraints to \gai. 
Solutions need to be delivered within the efficiency, effectiveness and cost constraints. 
So, where a real-world problem requires hourly solutions but the \gai task requires ninety minutes to run, compromises must be made to the effectiveness or cost to meet the efficiency constraint. 
Hardware accelerators for graph processing are specialized \ac{ASIC} optimized for the specific algorithm, representation, abstraction and programming model.
Because one system may need to support many \gai tasks, an accelerator will need to improve the performance of all those tasks to be a wise investment. 

The user then needs to decide whether to trade effectiveness for efficiency or pay a higher cost to achieve the desired results.
Gathering the data to make that decision has historically included choosing between a simple competitive benchmark of systems or an invasive workload analysis to determine which combination of hardware, representation, abstraction model and algorithm will best meet requirements. 

The challenges culminate in the research contribution of this thesis, \textit{determining \textit{if}, \textit{how} and \textit{when} to speed up problem-solving on linked data given a set of operating constraints.}
